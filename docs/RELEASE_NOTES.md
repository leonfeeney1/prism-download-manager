# Prism 1.6.1 — Fork release: macOS builds are back.

A fast, open-source download manager for Windows, Linux and macOS, with browser integration
and video downloads.

## What's new in 1.6.1

* **macOS builds are back.** The release ships Apple Silicon and Intel Mac builds again, alongside Windows and Linux — the macOS builds were dropped in 1.3.0 and return here. Everything from 1.6.0 is included: headless-browser downloads, the Ask Prism download agent, and all-networks-at-once bonding.
