# Prism 1.4.0 — Fork release: back to the 1.3.0 code.

A fast, open-source download manager for Windows, Linux and macOS, with browser integration
and video downloads.

## What's new in 1.4.0

* **This release returns the fork to the 1.3.0 code.** The 1.3.1 bot-check hand-back and the 1.3.2 sniffer fallback did not work out in practice, so they are removed — along with the upstream 1.2.4 changes that arrived in the November sync. What ships here is the 1.3.0 feature set: multi-source downloads, auto-extract and organize, LAN share, the natural-language grabber, and video subtitles plus translate, with no Hugging Face code.
